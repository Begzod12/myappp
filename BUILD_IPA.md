# Как получить .ipa для Sideloadly

Сам .ipa собирается на твоей стороне — либо в облаке Expo (EAS, Mac НЕ нужен),
либо на Mac в Xcode. Ниже — оба пути. Для Sideloadly подходит любой .ipa:
Sideloadly снимает старую подпись и подписывает заново под твой Apple ID.

────────────────────────────────────────────────────────
ПУТЬ 1. EAS Build (облако, без Mac) — рекомендую
────────────────────────────────────────────────────────

1. Установить EAS CLI и войти (аккаунт Expo бесплатный):
   npm install -g eas-cli
   eas login

2. В папке проекта инициализировать сборку:
   eas build:configure

3. Запустить сборку iOS по профилю preview (он уже в eas.json):
   eas build -p ios --profile preview

   • EAS спросит про подпись (credentials). Чтобы получить .ipa, ставящийся
     на устройство, нужен аккаунт Apple Developer и регистрация UDID твоего
     iPhone — EAS проведёт по шагам.
   • Если у тебя НЕТ платного Apple Developer аккаунта — см. Путь 2 (Mac),
     там работает и бесплатный Apple ID.

4. По окончании EAS даст ссылку на скачивание .ipa.
   Скачай его на компьютер.

5. Открой Sideloadly → перетащи .ipa → впиши свой Apple ID → Start.
   Приложение установится на подключённый iPhone.

ВАЖНО про сроки подписи в Sideloadly:
   • Бесплатный Apple ID — подпись живёт 7 дней, потом надо переподписать.
   • Платный Apple Developer ($99/год) — подпись на 1 год.

────────────────────────────────────────────────────────
ПУТЬ 2. Mac + Xcode (работает с бесплатным Apple ID)
────────────────────────────────────────────────────────

1. В папке проекта создать нативный iOS-проект:
   npx expo prebuild -p ios
   (появится папка ios/)

2. Открыть в Xcode:
   open ios/*.xcworkspace

3. В Xcode: Product → Archive.
4. В окне Organizer: Distribute App → выбрать вариант с экспортом .ipa
   (Ad Hoc / Development / Custom — для последующего sideload).
5. Получившийся .ipa скармливаешь в Sideloadly как в Пути 1.

────────────────────────────────────────────────────────
Почему .ipa нельзя выдать готовым из коробки
────────────────────────────────────────────────────────
iOS-бинарь компилируется только тулчейном Apple (Xcode на macOS) или
облачной сборкой Expo, и в обоих случаях завязан на твою учётку Apple.
Поэтому финальную сборку и подпись делаешь именно ты — проект к этому
полностью готов (App.js, src/, app.json, eas.json уже на месте).
