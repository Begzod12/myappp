# СИНАПС — нативное приложение (Expo)

3D-граф знакомых по теории рукопожатий. Работает на одном устройстве,
**без сервера**, данные сохраняются локально и не теряются при закрытии.

## Что нужно на компьютере (один раз)
- **Node.js** (LTS-версия) — https://nodejs.org
- На телефон поставь приложение **Expo Go** (есть в App Store и Google Play)
- Телефон и компьютер должны быть в одной Wi-Fi сети

## Запуск — два способа

### Способ A. Самый надёжный (рекомендую)
Если установка зависимостей будет ругаться на версии — этот путь сам подберёт
совместимые версии под актуальный Expo SDK:

```bash
# 1. создать чистый проект Expo
npx create-expo-app@latest synapse --template blank
cd synapse

# 2. заменить App.js и положить папку src из этого архива
#    (скопируй сюда App.js и папку src/ из присланного проекта)

# 3. поставить зависимости в правильных версиях
npx expo install expo-gl @react-native-async-storage/async-storage
npm install three@0.166.1 expo-three

# 4. запустить
npx expo start
```

### Способ B. Прямо из этого архива
```bash
cd synapse-app
npm install
npx expo start
```

После `npx expo start` в терминале появится QR-код.
Открой **Expo Go** на телефоне и отсканируй его — приложение запустится.

## Проверка локального сохранения
1. Открой приложение, добавь пару людей через «+».
2. Полностью закрой Expo Go (смахни из недавних).
3. Снова отсканируй QR / открой проект в Expo Go — добавленные люди на месте.

## Если что-то не запускается
Самое частое — несовместимость версий `three` и `expo-three` с текущим SDK.
Тогда используй Способ A: `npx expo install` подберёт версии автоматически,
а `expo-three`/`three` поставь последней совместимой парой.

## Структура
- `App.js` — экраны, состояние, локальное сохранение (AsyncStorage)
- `src/NeuronScene.js` — 3D-сцена нейронов (expo-gl + three)

## Чего здесь пока НЕТ (осознанно)
- Регистрации/входа и сервера — данные только на этом устройстве.
- Синхронизации между устройствами.
- Шрифты — системные (премиальные шрифты добавим позже через expo-font).

Это первый рабочий шаг «открывается и не теряет данные». Дальше — бэкенд,
